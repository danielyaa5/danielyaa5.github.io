See what’s left, and when it resets.

Your AI usage, on this Mac.

See recorded requests and tokens for today, the last 7 days or the last 30 days. Estimated API value uses published rates. It is an estimate of equivalent API usage, not a bill or money saved.

03

A quick check while you work.

Click a menu bar meter to see the quota panel, with percentages, reported reset times and a summary of recent recorded activity. Keep the numbers close without leaving them open all day.

Good to know

  • Start with one provider. Claude, ChatGPT / Codex and Google Antigravity have different connection requirements.
  • Quota readings can be unavailable or out of date. Check the observation time; reset times appear only when the provider reports them.
  • Local history is read through folders you choose. Usage summaries omit prompts and responses.
  • The menu bar and widgets work without a required dashboard or server.
  • Built for Apple silicon Macs with macOS 14 or later.

Get started

1. Download

Get AI Usage from the Mac App Store.

2. Choose a provider

Open the app and choose the tools you use, or choose Preview with sample data.

3. Connect a source

Connect a plan for quota, a history folder for recorded activity, or both. See Help for each provider.

4. Add a widget

Control-click the desktop, choose Edit Widgets and search for AI Usage. The menu bar is there for a quick check too.
