What's coming

Planned1.3 Being built

Both are being worked on now, and they go through the same testing as every update before they ship.

  • MacClean up big Messages attachments. A Messages source in the Mac sidebar lists the photos, videos and files in your conversations, with how much space each one takes. The App Store version opens each one in Messages so you can delete it there, and the direct download can delete them for you. It reads a copy of the Messages database, and deleting always happens in Messages itself. iPhone apps can't see Messages, so this one is Mac only.
  • More detailed bug reports. A report can include more about what went wrong, like a crash or a hang and what the app was doing just before, so problems get fixed faster. You can still read it before sending, and it never includes names or file paths.

IdeasBeing looked at Not promised
